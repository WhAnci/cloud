## How I use this

- **짧은 발견**은 `til/YYYY-MM-DD.md`
- **오래 참고할 개념**은 `notes/<topic>/<name>.md`
- **실습과 장애 해결**은 `labs/<name>.md`
- **시험 준비 중 자꾸 틀리는 개념**은 `certifications/<exam>.md`

형식보다 내용. 같은 내용을 두 번 정리하지 않아도 된다.
